# HAProxy

HAProxy — это высокопроизводительный и надёжный балансировщик нагрузки и прокси-сервер для приложений, использующих протоколы TCP и HTTP. Он обеспечивает распределение входящих соединений между группами серверов, что позволяет улучшить отказоустойчивость и масштабируемость системы.

## Основные возможности

- Балансировка нагрузки на уровне TCP и HTTP
- Поддержка SSL/TLS-трафика
- Мониторинг состояния бэкенд-серверов
- Гибкая система ACL и маршрутизации запросов
- Встроенная статистика для отслеживания производительности

# Расчет global параметров:
- maxconn = min((Available RAM - Buffer) / Memory per Connection, File Descriptors Limit)
- Available RAM - ~70% от общей памяти, остальное под нужды ОС
- tune.bufsize Размер буфера для обработки запросов. По умолчанию 16кб. Повышать если появляются ошибки HTTP header too large
- tune.maxrewrite Размер порции данных читаемых из сокета. Обычно tune.bufsize / 2
- ulimit-n Лимит на количество открытых файловых дескрипторов. 1 соединение = 2 FD. Перед увеличением этого параметра, нужно увеличить значение в /etc/security/limits.conf

## Установка

# Для работы Haproxy с другими контейнерами нужно создать сеть.
### Создадим отдельную сеть:
```
docker network create proxy
```

Проверяем:
```
docker network ls
```
Получим:
| NETWORK ID  | NAME   |
| ----------- |:------:|
| ...         | proxy  |

---

### Haproxy по умолчанию настроен чтобы работать через https.

Чтобы https работал, нужно создать сертификаты.
Для создания вы должны установить программу mkcert:

```
sudo apt install libnss3-tools
    -or-
sudo yum install nss-tools
    -or-
sudo pacman -S nss
    -or-
sudo zypper install mozilla-nss-tools
```

#### После установки mkcert нужно выполнить скрипт ./scripts/setup-certs.sh.

---

__Примечание:__ если вы используете __docker в windows__, то вам нужно скопировать корневой
сертификат mkcert на хост машину и установить его.

Выполните команду в wsl заменив __<имя_пользователя>__ на ваше имя пользователя на хост машине:
```
cp "$(mkcert -CAROOT)/rootCA.pem" /mnt/c/Users/<имя_пользователя>/rootCA.crt
```

После чего в powershell Windows выполните команду заменив __<имя_пользователя>__ на ваше имя пользователя на хост машине и нажмите Да:
```
certutil -addstore -user Root C:\Users\<имя_пользователя>\rootCA.crt
```

__Перезапустите браузер__

---

### Запуск haproxy:

```
docker compose up -d
```
